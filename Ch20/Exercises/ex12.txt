unsigned short create_short(unsigned char high_byte, unsigned char low_byte)
{
    return high_byte << 8 + low_byte;
}

Bitwise operator has lower precedence than arithmetic operators.
So we have to additional parentheses in return statement.

unsigned short create_short(unsigned char high_byte, unsigned char low_byte)
{
    return (high_byte << 8) + low_byte;
}
